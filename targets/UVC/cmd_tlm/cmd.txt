###############################################################################
# Insta360 Link / UVC camera command packets.
#
# Wire format (host -> device, framed by LengthProtocol):
#   [SYNC u16 = 0xAABB][LEN u16 = total bytes][PKT_ID u8][PAYLOAD...]
#
# Most V4L2-standard controls share PKT_ID 0x01 (SET_V4L2_CTRL). Payload =
#   [VALUE i32][NAME utf-8 string to end of packet]
# Each COMMAND fixes its own NAME default so the bridge stays a thin proxy:
# it just calls `v4l2-ctl --set-ctrl <NAME>=<VALUE>`.
#
# Non-V4L2 commands (relative move, gimbal reset, XU vendor controls, presets,
# status) keep their own PKT_IDs.
###############################################################################
